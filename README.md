## 🎯 About NeuralLens

**NeuralLens** is an interactive deep learning visualization platform designed to help students, teachers, and AI enthusiasts understand what happens inside a neural network.

Traditional deep learning education often relies on mathematical equations, static diagrams, and theoretical explanations. Although these approaches are important, they can make it difficult to understand how data moves through a neural network, how predictions are generated, and how a model learns from its mistakes.

NeuralLens aims to solve this problem by turning the internal workings of deep learning algorithms into an interactive visual experience.

Users can explore neural network layers, observe forward propagation, understand activation functions, inspect prediction probabilities, and visualize how errors propagate backward during training.

Instead of treating a neural network as a black box, **NeuralLens opens the black box and makes its internal computations visible.**

### 💡 Our Vision

Make deep learning easier to understand by connecting mathematical theory with interactive visual explanations.

## 🔄 How NeuralLens Works

NeuralLens follows a visualization pipeline that connects user input, neural network computation, and an interactive explanation of the result.

1. **Choose a Model** — Select a supported neural network or learning experiment.
2. **Configure the Network** — Adjust available parameters, layers, or input values.
3. **Provide Input Data** — Enter sample values or select a supported dataset.
4. **Execute Forward Propagation** — Process input values through the network.
5. **Visualize Activations** — Inspect the values generated by neurons and layers.
6. **Generate a Prediction** — Display the model's output and prediction probabilities where applicable.
7. **Calculate the Loss** — Compare predictions with target values during supervised learning.
8. **Explore Backpropagation** — Visualize gradients and their effect on model parameters.
9. **Observe Learning** — Track changes in loss, accuracy, weights, and other available metrics.

## 🔬 What Can You Explore?

### 1. Neural Network Fundamentals

Understand the building blocks of a neural network.

| Concept | What You Can Learn |
|---|---|
| Neurons | How individual units process information |
| Layers | How data passes through a network |
| Weights | How connections influence computations |
| Biases | How learnable offsets affect neuron outputs |
| Activation Functions | How nonlinear transformations work |
| Forward Propagation | How inputs become predictions |
| Loss Functions | How prediction errors are measured |
| Backpropagation | How gradients are calculated |
| Gradient Descent | How model parameters are optimized |

### 2. Activation Functions

Explore how activation functions transform their inputs.

| Function | Mathematical Definition | Purpose |
|---|---|---|
| ReLU | \(f(x)=\max(0,x)\) | Introduces nonlinearity while setting negative inputs to zero |
| Sigmoid | \(f(x)=\frac{1}{1+e^{-x}}\) | Maps values to the interval (0, 1) |
| Tanh | \(f(x)=\tanh(x)\) | Maps values to the interval (-1, 1) |
| Softmax | \(f(x_i)=\frac{e^{x_i}}{\sum_j e^{x_j}}\) | Converts logits into a probability distribution |

### 3. Forward Propagation

For a simple fully connected layer, the computation is:

\[
z=Wx+b
\]

\[
a=f(z)
\]

Where:

- \(x\) represents the input vector.
- \(W\) represents the weight matrix.
- \(b\) represents the bias vector.
- \(z\) represents the pre-activation values.
- \(f\) represents the activation function.
- \(a\) represents the output activations.

NeuralLens can display these operations step by step to show how a layer transforms its input.

### 4. Backpropagation

Backpropagation calculates gradients that indicate how changes in parameters affect the loss.

A gradient-descent update can be expressed as:

\[
W_{\text{new}}=W_{\text{old}}-\eta\frac{\partial L}{\partial W}
\]

Where:

- \(W\) represents the model weights.
- \(\eta\) represents the learning rate.
- \(L\) represents the loss function.
- \(\frac{\partial L}{\partial W}\) represents the gradient of the loss with respect to the weights.

The visualization can help users understand why weights change and how these changes influence future predictions.

## ⚡ Getting Started

### Prerequisites

Install the following tools before running the application:

- Python 3.10 or a compatible version supported by the selected dependencies.
- Node.js and npm.
- Git.
- A code editor such as Visual Studio Code.

### 1. Clone the Repository

```bash
git clone https://github.com/ujjwal-oo/NeuralLens.git
cd NeuralLens
```

Replace the placeholder with the actual GitHub repository URL.

### 2. Set Up the Backend

Create and activate a Python virtual environment.

**macOS / Linux:**

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
```

**Windows PowerShell:**

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Install the backend dependencies:

```bash
pip install -r requirements.txt
```

### 3. Start the Backend

From the project root, run:

```bash
python -m uvicorn backend.app.main:app --reload
```

Backend URL:

```text
http://127.0.0.1:8000
```

Interactive API documentation:

```text
http://127.0.0.1:8000/docs
```

The command assumes that `backend/app/main.py` exposes a FastAPI instance named `app` and that the package structure matches the example above.

### 4. Set Up the Frontend

Open a separate terminal and navigate to the frontend:

```bash
cd frontend
npm install
```

Create a `.env.local` file inside `frontend/`:

```env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

Start the development server:

```bash
npm run dev
```

Frontend URL:

```text
http://localhost:3000
```

### 5. Open NeuralLens

Visit `http://localhost:3000` in your browser.

Once the backend and frontend have been implemented and started successfully, you can use the available playground to explore the supported visualizations.

## 📊 Evaluation Strategy

NeuralLens is an educational visualization platform, so evaluation should consider both mathematical correctness and usability.

| Evaluation Area | What to Measure |
|---|---|
| Mathematical Correctness | Agreement with reference calculations |
| Prediction Correctness | Agreement with the underlying model's output |
| Gradient Correctness | Agreement with automatic differentiation or numerical checks |
| Visualization Accuracy | Whether displayed values match actual computations |
| Performance | Time taken to execute an experiment and render results |
| Usability | Whether students can navigate and understand the visualizations |
| Educational Value | Whether users better understand the demonstrated concepts |

Model accuracy is relevant when evaluating a trained predictive model, but it is not sufficient to measure the educational effectiveness of NeuralLens.

## ⚠️ Limitations

- Complex neural networks may be difficult to visualize without simplifying their representations.
- Large networks can require substantial computation and rendering resources.
- Visualizations must be carefully synchronized with the underlying numerical calculations.
- Simplified demonstrations may omit implementation details present in production deep learning systems.
- Training speed depends on model size, dataset size, and available hardware.
- Understanding a visualization still requires some familiarity with mathematical and machine learning concepts.
- Supported algorithms and features depend on the implemented version of the platform.
